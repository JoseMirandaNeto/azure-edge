# Kit de Projeto — Codinome "AZURE EDGE" (MMORPG Action Hack & Slash 3D, Browser-first)

Conteúdo:
- `00_AGENT_PROMPT.md` — prompt mestre para o agente IA (cole como system prompt / primeira mensagem).
- `AGENTS.md` — regras do projeto (também use como `CLAUDE.md`, `.cursorrules`, etc.).
- `docs/GDD.md` — Game Design Document.
- `docs/ARCHITECTURE.md` — stack técnica, netcode, estrutura do monorepo.
- `docs/CHARACTER_PIPELINE.md` — geração procedural de personagens (estilo anime semi-realista).
- `docs/COMBAT_SPEC.md` — especificação de combate (frames, hitboxes, números).
- `docs/ROADMAP.md` — milestones com critérios de aceite.
- `docs/PROTOCOL.md` — protocolo de rede e schemas.

Como usar: coloque tudo na raiz do repo, abra o agente e envie: "Leia 00_AGENT_PROMPT.md e execute o Milestone M0."
Observação: nomes de IP de terceiros (Vindictus, Cabal, Aika) são só REFERÊNCIA de gameplay/feeling. Não copie assets, nomes, mapas, personagens ou código.
